Simon Game

A browser-based Simon Game built using HTML, CSS, and JavaScript.

Technologies Used:
. HTML5
. CSS3
. JavaScript

How to Play
1. Press any key to start the game.
2. Watch the sequence of flashing buttons carefully.
3. Click the buttons in the same order.
4. Each successful round increases the level.
5. The sequence becomes longer as you progress.
6. Making a mistake ends the game.
How to Run
1. Clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start playing the game.
